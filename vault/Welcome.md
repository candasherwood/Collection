# Welcome to jadeli

jadeli is a local-first place for notes and books. Everything you write is a plain
markdown file inside this folder — no database, no lock-in, no account.

## Where things live

- **This vault** — the folder you opened. Every `.md` file in it is a note.
- **Books** — an ordered manuscript built from ordinary notes. See [[Books]].
- **The Lantern's Edge** — the demo novel's own project folder: the chapters plus
  a full story bible. Start at [[The Lantern's Edge — Story Bible]].
- **Exports** — combined manuscripts land here when you export.

## Try this

1. Open the **Books** tab in the left rail and click *The Lantern's Edge*.
2. Add a chapter, write a few lines, and open the **Outline** panel on the right.
3. Press `Ctrl+Shift+\` for a second pane — a chapter on one side, its outline on
   the other.
4. Hit `Ctrl+O` to jump between notes, or `Ctrl+Shift+F` to search the whole vault.
5. Open the **Graph** tab to see how notes link together.

Wiki links look like this: [[Markdown Cheatsheet]] — if a note doesn't exist yet,
clicking the link creates it. Tags look like this: #welcome — click one to search
for it.

> [!tip] Autosave
> jadeli saves as you type. `Ctrl+S` forces an immediate save.
