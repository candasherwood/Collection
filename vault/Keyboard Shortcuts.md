# Keyboard Shortcuts

| Keys | Action |
| --- | --- |
| `Ctrl+O` or `Ctrl+P` | Jump to a note |
| `Ctrl+N` | New note |
| `Ctrl+S` | Save now (autosave is already on) |
| `Ctrl+W` | Close the current tab |
| `Ctrl+E` | Cycle write → split → read for the focused pane |
| `Ctrl+Shift+\` | Split panes on / off |
| `Ctrl+Shift+F` | Search the whole vault |
| `Ctrl+\` | Show / hide the sidebar |
| `Ctrl+B` / `Ctrl+I` | Bold / italic in the editor |
| `Ctrl+K` | Wrap the selection as a link |
| `Tab` / `Shift+Tab` | Indent / outdent (or tab inside the caret) |

## Two panes

- Click the split button in the titlebar (or `Ctrl+Shift+\`) to open a second
  pane. Each pane keeps its own tabs, so you can hold an outline on one side and
  the chapter you are drafting on the other.
- Click into a pane to make it the active one; new notes, wiki links and the
  outline / backlinks panel follow the active pane.
- Right-click a tab and choose **Open in other pane** — or right-click a note in
  the file tree. The same note in both panes stays in sync.
- Click the × in the second pane's toolbar, or press the shortcut again, to go
  back to a single pane.

## Editor comforts

- Lists continue themselves when you press `Enter`; press it again on an empty item to end the list.
- Task items: `- [ ] something` and `- [x] done`.
- `Ctrl+E` cycles between editing, split view and reading view.

> [!note] Reading mode
> Reading mode uses a serif face and a wider measure, which is nicer for
> proofreading a chapter than for writing it.
